\# 🪰 JeevanFlySolver (jeevanflysolver.com)



An interactive 3D Fruit Fly (\*Drosophila melanogaster\*) Rubik's Cube Sanctuary simulator built with Three.js.



\## 🌟 Features

\- \*\*Non-Cheating 3D Cube Engine\*\*: Real 3D pivot matrices turning 27 separate cubie objects.

\- \*\*Anatomical Limb Movement\*\*: Front legs visibly trigger face turns.

\- \*\*Living Sanctuary Habitat\*\*: Soft leaf bed, banana plate, and water dish.

\- \*\*Fatigue \& Rest Routine\*\*: Automatically triggers 2-minute sleep breaks on the leaf bed when stamina drops below 12%.

\- \*\*Fly Neural Notebook\*\*: Discovers and logs move patterns into its memory drawer.
